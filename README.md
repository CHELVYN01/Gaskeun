# Gaskeun — Habit Journey Tracker

> "Gak perlu sempurna, yang penting gaskeun aja dulu!"

Gaskeun adalah aplikasi mobile habit tracker minimalis yang terinspirasi dari prinsip Atomic Habits oleh James Clear. Aplikasi ini dirancang untuk membantumu fokus pada satu perubahan kecil setiap harinya melalui sistem perjalanan level yang sederhana namun disiplin.

---

## Fitur Utama

### Visual Journey Map
Visualisasi progres dalam bentuk jalur tangga (Staircase) yang minimalis dengan tema pastel. Jalur ini membantumu melihat sejauh mana kamu sudah melangkah dari level dasar hingga menjadi master.

### Weekly Mastery System
Membangun habit bukan soal satu malam. Di Gaskeun, kamu harus menyelesaikan tantangan yang sama selama 7 hari berturut-turut sebelum bisa naik ke level berikutnya. Konsistensi adalah kunci utama.

### Anti-Cheating Daily Cooldown
Tombol "Gaskeun!" memiliki fitur hitung mundur (cooldown). Kamu hanya bisa menandai satu hari selesai per hari. Jika sudah, tombol akan terkunci dan menampilkan hitung mundur hingga tengah malam untuk tantangan berikutnya.

### Daily Motivational Quotes
Setiap hari di setiap level, kamu akan mendapatkan kalimat semangat yang berbeda untuk menemani perjuanganmu membangun kebiasaan baru secara bertahap.

### Privacy First
Semua data disimpan secara lokal di perangkat menggunakan SQLite. Tidak ada sinkronisasi cloud atau pelacakan data, sehingga privasi pengguna terjaga sepenuhnya.

---

## Teknologi

- Framework: React Native with Expo SDK
- Language: TypeScript
- Database: SQLite (expo-sqlite)
- Navigation: React Navigation v6

---

## Cara Menjalankan Project

1. Clone Repository
   ```bash
   git clone https://github.com/CHELVYN01/Gaskeun.git
   cd Gaskeun
   ```

2. Install Dependencies
   ```bash
   npm install
   ```

3. Jalankan Aplikasi
   ```bash
   npx expo start
   ```
